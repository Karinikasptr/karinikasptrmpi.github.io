🎯 Tujuan Pembelajaran

Setelah mempelajari materi ini, murid mampu:

1

Melakukan pencarian data pada lembar kerja menggunakan fitur filter, sort, dan fungsi pencarian (VLOOKUP/Find) untuk menemukan informasi spesifik secara efisien.

2

Membuat visualisasi data dalam bentuk grafik (batang, garis, lingkaran) yang tepat sesuai jenis data untuk memudahkan interpretasi informasi.

3

Meringkas data menggunakan fungsi agregasi (SUM, AVERAGE, MAX, MIN, COUNT) untuk menghasilkan informasi ringkas yang bermakna.

4

Menyajikan hasil analisis data secara logis dan komunikatif sebagai dasar pengambilan keputusan sederhana.

📖 Materi Pembelajaran
🔍

Pencarian Data

Menemukan data tertentu dengan cepat memakai fitur Find, Filter, dan fungsi VLOOKUP pada baris/kolom besar.

📊

Visualisasi Data

Mengubah angka menjadi grafik batang, garis, atau lingkaran agar pola data mudah dibaca dan dibandingkan.

🧮

Peringkasan Data

Fungsi SUM, AVERAGE, MAX, MIN, dan COUNT dipakai untuk merangkum ribuan data menjadi beberapa angka kunci.

🧹

Pembersihan Data

Menghapus duplikat, memperbaiki format, dan menyeragamkan satuan agar data siap dianalisis dengan akurat.

🔽

Sortir & Filter

Mengurutkan data (A–Z, terbesar–terkecil) dan menyaring baris sesuai kriteria tertentu untuk fokus analisis.

💬

Interpretasi Hasil

Membaca hasil ringkasan dan grafik untuk menarik kesimpulan serta mendukung pengambilan keputusan.
